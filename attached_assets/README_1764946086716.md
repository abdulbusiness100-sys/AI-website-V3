# SPIDXR - Premium Urban Concierge Service

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Node.js Version](https://img.shields.io/badge/node-%3E%3D%2018.0.0-brightgreen)](https://nodejs.org/)

SPIDXR is Manchester's premier concierge service offering package collection, food delivery, grocery shopping, and personal assistance. Our platform combines modern web technologies with professional service delivery to simplify urban living.

## 🚀 Features

- **Modern Web Application**: Built with React 18, TypeScript, and Vite
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Professional Services**: Comprehensive concierge service offerings
- **Investor Ready**: Complete business presentation and financial projections
- **Performance Optimized**: Fast loading times and smooth animations
- **SEO Optimized**: Complete meta tags, sitemap, and structured data
- **Security First**: Comprehensive security headers and CORS protection

## 🛠️ Tech Stack

### Frontend
- **React 18** - Modern UI library

## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/spidxr-website.git
   cd spidxr-website
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

4. **Start development server**
   ```bash
   npm run dev
   ```

5. **Open your browser**
   Navigate to `http://localhost:3001`

## ⚙️ Environment Configuration

Create a `.env` file in the root directory:

```env
# Database
DATABASE_URL=postgresql://username:password@localhost:5432/spidxr

# EmailJS (for contact forms)
VITE_EMAILJS_PUBLIC_KEY=your_emailjs_public_key
VITE_EMAILJS_SERVICE_ID=your_emailjs_service_id
VITE_EMAILJS_TEMPLATE_ID=your_emailjs_template_id

# Analytics
VITE_GA_TRACKING_ID=G-XXXXXXXXXX

# Production settings
NODE_ENV=production
PORT=3001
SESSION_SECRET=your_super_secret_session_key
```
